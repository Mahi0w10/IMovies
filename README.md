# 🎬 IMovies — Movie Ticket Booking Platform

**IMovies** is a full-stack web application designed to make movie discovery and ticket booking simple and convenient. Users can explore movies, view details, and book movie tickets through an easy-to-use interface.

🌐 **Live Demo:** [IMovies](https://i-movies-mauve.vercel.app)

🚀 **Backend API:** [IMovies Backend](https://imovies-backend-wm25.onrender.com)

---

## Features

* 🎥 Browse and explore movies.
* 🎟️ Book movie tickets online.
* 🖥️ Responsive and user-friendly interface.
* 🔗 Frontend and backend integration.
* 🗄️ Database integration for application data.
* ⚡ REST API powered by Express.js.

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Mahi0w10/IMovies.git
cd IMovies
```

### 2. Start the frontend

```bash
cd client
npm install
npm run dev
```

### 3. Start the backend

Open a separate terminal:

```bash
cd server
npm install
npm start
```

**Note:** The backend may require environment variables, including the MongoDB connection string and port configuration. Set these in a local `.env` file according to your server code. Never upload database credentials or secret keys to GitHub.
